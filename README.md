# 🚀 Projets Full-Stack — Spring Boot & Angular

Ce dépôt regroupe **trois applications de gestion** que j'ai réalisées en **Java / Spring Boot** pour le backend et **Angular** pour le frontend.

Chaque projet a été conçu selon une **architecture microservices** : l'application est découpée en services indépendants, chacun responsable d'un domaine métier précis, qui communiquent entre eux via des API REST. Cette approche rend les applications plus modulaires, évolutives et faciles à maintenir.

---

## 📁 Les projets

| Projet | Description |
| ------ | ----------- |
| 💼 **management-accounting** | Application de gestion comptabilité électronique |
| ⚽ **management-football** | Application de gestion des événements footballistique |
| 🎓 **management-training** | Application de gestion de formations |

---

## 🛠️ Stack technique

- **Backend** : Java, Spring Boot, Spring Data JPA, Spring Cloud
- **Frontend** : Angular, TypeScript, HTML5, CSS3
- **Architecture** : Microservices, API REST
- **Base de données** : MySQL/PostgreSQL

---

## 🏗️ Architecture

Les projets reposent sur une architecture microservices :

- des **services backend indépendants** développés avec Spring Boot ;
- une **communication via API REST** entre les services ;
- un **frontend Angular** qui consomme ces services ;
- une **séparation claire des responsabilités** entre les différents modules.
